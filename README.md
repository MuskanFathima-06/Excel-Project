# 🚴‍♀️ Excel Data Cleaning & Dashboard Project

## 📊 Overview
This project showcases my ability to **clean, transform, and visualize data in Microsoft Excel**.  
Using a **Bike Sales dataset**, I performed data cleaning to fix inconsistencies and then built **Pivot Tables, Charts, and an interactive Dashboard** to uncover customer purchasing trends.

---

## 🔧 Key Tasks
- **Data Cleaning**
  - Removed duplicates and corrected date formats.
  - Standardized categorical values (e.g., `M` → Married, `S` → Single).
  - Normalized income values into numeric format.
  - Unified education levels for clarity.
  - Categorized age groups (Young Adult, Middle‑Aged, Old).
  - Cleaned commute distance entries (e.g., `10+ miles` → More than 10 miles).

- **Dashboard Development**
  - Created Pivot Tables summarizing income, age brackets, commute distance, and purchase behavior.
  - Designed Charts (bar and line) to visualize relationships between gender, income, and bike purchases.
  - Built a clean, interactive Dashboard combining filters and visuals for quick insights.

---

## Outcomes
- A **structured dataset** ready for analysis.
- An **interactive Excel dashboard** revealing how demographics, income, and commute distance influence bike purchasing decisions.
- Demonstrated proficiency in **Excel data cleaning, transformation, and visualization**.
